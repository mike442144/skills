# 医药集采研究追踪（Pharma VBP Tracker）

## 概述

本技能用于系统研究上市公司受药品集中带量采购（VBP）影响，回答两个层面的问题：

1. **行业维度（What & When）**：集采政策时间线是什么？各省/国采执行节奏如何？每次集采实际影响多大？哪些品种被纳入？
2. **公司维度（How Much）**：公司产品被纳入集采了吗？对营收影响多大？已成事实的有对比数据；将成事实的拆解院内院外渠道，评估影响面。

**覆盖范围**：中成药集采 + 化学药集采（国采/省际联盟/区域集采）

## 触发条件

当用户提出以下类型的需求时，触发本技能：

- 某公司/某药品有没有集采风险
- 集采对XX公司的影响有多大
- XX药品的集采进度跟踪
- 医药集采政策时间线梳理
- 类似表达："XX有没有集采问题"、"集采对XX影响"、"XX药品集采情况"

## 工作流程

### Step 0：明确研究范围与初始化

**目标**：确认用户要研究的对象（行业/公司/品种），划定边界。

**操作**：

1. 从用户输入中提取研究目标：
   - **公司研究**：如"马应龙集采风险"、"华特达因集采影响"
   - **行业研究**：如"中成药集采时间线"、"化学药国采节奏"
   - **品种研究**：如"感冒灵集采情况"、"伊可新有没有进集采"
2. 确认品类属性：
   - 中成药 → 适用中成药集采规则（湖北牵头联盟、全国联采、OTC纳入等）
   - 化学药 → 适用化学药集采规则（国采九批+、省际联盟、区域集采）
3. 新建文件夹：`./[公司名或主题]_集采研究/`，后续所有文件存放于此。

**输出**：研究范围确认 + 文件夹初始化。

### Step 1：政策时间线梳理（行业维度）

**目标**：建立集采政策完整时间线，回答"集采是什么时候开始的、执行到哪了、下一步是什么"。

**操作**：

#### 1.1 区分中成药与化学药集采体系

| 维度 | 中成药集采 | 化学药集采 |
|------|-----------|-----------|
| 牵头方 | 湖北省医药价格和招标采购服务网 | 国家医保局（国采）/ 省级医保局（省采） |
| 体制 | 省际联盟 → 全国联采 | 国家组织 → 全国执行 |
| 批次 | 已执行四批（2021-2026） | 已执行九批以上（2018-2024） |
| 品种 | 口服/注射液/OTC/进口中成药 | 通过一致性评价的仿制药 |
| 降幅 | 42%→49%→68%（逐批攀升） | 50%-90%+（视竞争格局） |
| 特点 | 无一致性评价、独家品种多、同方异名 | 一致性评价为门槛、竞争格局清晰 |
| 规则 | 价格分60%+技术评价40% | 最低价中标→品间熔断→Top6淘汰 |
| 周期 | ~2.5年（至2027/2028底） | 3年（第9批延至4年） |
| 供应 | 单一供应商 | 一省双供/一主两备 |

#### 1.2 搜索政策时间线

使用WebSearch进行多轮搜索：

- **中成药**：搜索"中成药集采 第X批 时间线"、"全国中成药联采 公告"、"湖北中成药集采 中选结果"
- **化学药**：搜索"国家组织药品集采 第X批 中选结果"、"化学药集采 执行省份"、"区域联盟集采 品种"
- 搜索公司相关集采："[公司名] 集采 中选/落标/纳入"
- 数据源优先级：国家医保局官网 > 省级集采平台 > 上市公司公告 > 券商研报 > 权威财经媒体

#### 1.3 构建时间线表格

对每批/每次集采，记录以下要素：

| 字段 | 说明 |
|------|------|
| 批次/名称 | 如"第三批全国中成药集采"、"第九批国家集采" |
| 发布时间 | 公告/文件发布日期 |
| 开标时间 | 实际开标日期 |
| 落地时间 | 各省陆续执行的时间范围 |
| 采购周期 | 如"至2027年底" |
| 参与省份 | 覆盖范围（19省/30省/31省/全国） |
| 品种数量 | 纳入集采的药品数量 |
| 中选率 | 中选企业/产品比例 |
| 平均降幅 | 价格降幅（如有） |
| 中选规则 | 如"Top6淘汰"、"一主两备"、"价格分60%+技术40%" |
| 历史突破 | 该批次的特殊意义（如首次纳入OTC、首次纳入注射液） |

**输出文件**：`政策时间线.md`

### Step 3：公司集采影响分析（公司维度）

**目标**：针对具体公司，量化集采对营收的影响，拆解院内院外渠道结构。

**操作**：

#### 3.1 产品纳入状态梳理

搜索确认公司核心产品是否被纳入集采：

- 搜索："[公司名] 集采 品种"、"[公司名] 中选/落标"、"[产品名] 集采"
- 查阅公司年报/公告中关于集采影响的披露
- 确认每个核心产品的状态：
  - **已中选**：已执行集采，有实际影响数据
  - **待执行**：已公布中选结果，尚未落地
  - **未纳入**：暂未纳入集采，但存在预期

#### 3.2 营收影响量化（已成事实）

对已执行集采的产品，量化影响：

| 产品 | 集采前收入 | 集采后收入 | 变化幅度 | 集采前毛利率 | 集采后毛利率 | 变化幅度 |
|------|-----------|-----------|---------|------------|------------|---------|
| | | | | | | |

数据来源：公司年报、季报、业绩说明会披露。如无精确数据，标注"待确认"。

#### 3.3 营收影响预测（将成事实）

对已纳入但尚未执行的品种，预测影响：

| 产品 | 2025年收入 | 占营收比 | 集采降幅预期 | 影响评估 |
|------|-----------|---------|------------|---------|
| | | | 参考历史批次降幅 | 定性判断 |

#### 3.4 院内院外渠道拆解

**核心逻辑**：院内处方渠道受集采直接影响，院外OTC/零售渠道受集采影响较小。

搜索公司产品的渠道结构：

- 院内渠道占比（医院、基层医疗机构）
- 院外渠道占比（零售药店、电商、第三终端）
- OTC品种 vs 处方药品种分类

| 渠道 | 占比 | 集采影响 | 说明 |
|------|------|---------|------|
| 院内处方 | | 直接（落标=丢标） | |
| 院外零售 | | 间接（价格传导） | |
| 电商 | | 较弱 | |
| 第三终端 | | 较弱 | 基层医疗机构、诊所 |

**渠道韧性判断**：
- 院外占比>90%的品种：对集采落标有较强缓冲能力（如华特达因伊可新）
- 院内占比>70%的品种：集采落标将导致收入大幅下滑
- 院内50-70%：中等风险，取决于竞争格局

#### 3.5 战略应对解读

**分析公司面对集采的战略意图和应对策略**：

1. **公司官方态度**（引用年报/公告/业绩会原话）
2. **集采策略判断**（三选一）：
   - "全面参与"型（以量换价，积极竞标）
   - "观望保利润"型（放弃医院端，聚焦零售）
   - "被动接受"型（无可选择，被迫跟进）
3. **同系产品竞品对比**（**必须对比至少 2 家有同系产品的企业**）：

| 同系产品领域 | 标的公司 | 对标企业示例 |
|---|---|---|
| 健胃消食/消化类 | 华润江中 | 济川药业、葵花药业 |
| 血塞通/心脑血管 | 昆药集团 | 珍宝岛、中恒集团 |
| 小儿肺热咳喘/儿科 | 华特达因 | 葫芦娃药业、葵花药业 |
| 贴膏剂/外用 | 羚锐制药 | 奇正藏药、云南白药 |
| 感冒灵/解热镇痛 | 华润三九 | 以岭药业、白云山 |

对比维度：
- 各家中选状态（中选/落标/未参与）
- 各家中选价格/降幅差异
- 各家的渠道策略差异（院内 vs 院外）
- 谁更激进/保守，为什么

4. **策略可行性分析**：支持因素 vs 反对因素

#### 3.6 收入冲击情景分析

**对集采将成事实的产品，做三情景预判**：

| 情景 | 降价幅度 | 收入影响 | 毛利影响 | 说明 |
|------|---------|---------|---------|------|
| 保守 | 参考历史同类降幅下限 | 计算值 | 计算值 | 乐观假设：以量补价成功 |
| 中性 | 参考历史同类降幅均值 | 计算值 | 计算值 | 基准假设：量价部分抵消 |
| 乐观 | 参考历史同类降幅上限 | 计算值 | 计算值 | 悲观假设：丢标或大幅降价 |

**计算逻辑**：
- 收入影响 = 产品收入 × 降价幅度 × 院内占比
- 毛利影响 = 收入影响 × (1 - 原毛利率 / (1 - 降价幅度))

#### 3.7 盈利结构性分析

**集采产品 vs 非集采产品毛利率对比**：

| 类别 | 毛利率 | 趋势 | 说明 |
|------|--------|------|------|
| 集采产品 | | ↓ | 价格下降压缩利润空间 |
| 非集采产品 | | →/↑ | 未受集采影响或受益于竞品出局 |
| 整体 | | | 结构性分化程度 |

**成本对冲能力评估**：
- 原料药自供比例：自供率高→成本可控
- 规模效应：集采放量能否抵消降价损失
- 销售费用率变化：集采后销售费用是否同步压降

**输出文件**：`[公司名]_集采影响分析.md`

### Step 4：风险评级与综合评估

**目标**：综合产品、渠道、收入、盈利能力数据，给出集采风险评级，输出完整分析报告。

**操作**：

#### 4.0 核心结论（放在报告开头）

**报告必须以核心结论章节开篇**，包含以下三部分：

1. **一句话定性判断**：用一句话概括公司集采风险的核心特征
   - 例："核心大单品全面纳入，价格体系面临重构，短期阵痛不可避免"（葵花药业）
   - 例："短期阵痛，长期无碍，品牌韧性支撑零售基本盘"（华润江中）
   - 要求：有观点、有态度，不可只列数据

2. **核心数据汇总表**：

| 维度 | 内容 |
|------|------|
| **已纳入集采品种** | 数量及名称 |
| **中选状态** | 已中选/待执行/未纳入 |
| **预期降幅** | 参考历史批次 |
| **整体风险等级** | 高/中高/中/低（可用星级表示） |

3. **核心逻辑简述**（3-4条）：
   - 为什么是这个风险等级？
   - 最大的风险点是什么？
   - 最大的缓冲因素是什么？

#### 4.1 四维度风险评估矩阵

从四个维度综合评估公司集采风险敞口：

| 评估维度 | 核心指标 | 权重 |
|---------|---------|------|
| **1. 集采风险敞口** | 集采产品营收占比、中标价格降幅、续标价格波动 | 35% |
| **2. 渠道韧性** | 院外占比、OTC品种占比、电商渠道成熟度 | 25% |
| **3. 盈利结构性** | 集采/非集采毛利率分化、销售费用率变化、成本对冲能力 | 25% |
| **4. 创新对冲** | 创新药/独家品种占比、研发投入强度、管线储备 | 15% |

#### 4.2 风险评级标准

| 风险等级 | 判定标准 | 应对建议 |
|---------|---------|---------|
| **高** | 核心产品已中选+降幅>50%+院内占比>70%+创新管线薄弱 | 关注集采后收入恢复情况 |
| **中高** | 核心产品待执行+预计降幅大+院内占比较高 | 预判落标/中选情景下的收入变化 |
| **中** | 部分品种纳入+渠道分散+有一定创新对冲 | 持续跟踪集采执行进度 |
| **低** | 品种未纳入/院外占比>90%/创新管线丰富 | 短期无重大风险，关注长期纳入预期 |

#### 4.3 短期风险展望（1-2年）

**按时间维度分层评估短期风险**，每项标注可能性和影响程度：

| 风险因素 | 可能性 | 影响程度 | 说明 |
|---------|-------|---------|------|
| | 高/中/低 | 高/中/低 | 具体描述 |

#### 4.4 中长期风险展望（3-5年）

**按时间维度分层评估中长期风险**，关注趋势性变化：

| 风险因素 | 可能性 | 影响程度 | 说明 |
|---------|-------|---------|------|
| | 高/中/低 | 高/中/低 | 具体描述 |

#### 4.5 政策趋势判断

**对集采政策走向的前瞻判断**，列出 3-4 条：
- 后续批次可能覆盖的品种范围
- 规则变化趋势（如"不唯低价论"导向）
- 采购周期和续标预期
- 对行业格局的潜在影响

#### 4.6 战略应对能力评估（加减分项）

**加分项**（提升韧性）：
- ✅ 规模化生产+原料自产形成成本护城河
- ✅ 院外渠道（零售药店、线上、"双通道"）拓展能力强
- ✅ 创新药/独家剂型布局充分，享受集采"安全边界"
- ✅ 供应链稳定履约记录良好，质量控制体系完善

**减分项**（预警信号）：
- ⚠️ 核心单品高度依赖集采且未中标
- ⚠️ 成本控制能力弱、销售费用刚性
- ⚠️ 创新转型滞后，过度依赖中低端同质化品种
- ⚠️ 频繁集采周期下供应链投入不足

## 重要规则

### 数据获取原则
- **必须**从正规渠道获取数据：国家医保局官网、省级集采平台、上市公司年报/公告、权威财经媒体
- **不可**凭记忆编造集采批次、时间、降幅、品种等数据
- **不可**估算或用历史数据替代实时数据
- 对不确定的数据，标注"待验证"
- 数据有矛盾时，以权威来源为准

### 文风要求
- 避免模糊表述，量化拆解优先：有数字用数字，无数字标"待确认"
- 院内院外渠道必须拆解清楚
- **核心结论必须有判断力**：不可只列数据，必须有一句话定性判断
- **竞品对比必须有同系产品**：每次分析必须对比至少 2 家有同系产品（同品种或同治疗领域）的企业

### 中成药 vs 化学药边界
- 明确区分中成药和化学药属性
- 华特达因（化学药）不适用中成药集采逻辑
- 云南白药、羚锐制药（中成药）适用中成药集采逻辑
- 如公司产品线同时包含中成药和化学药，需分别适用不同集采规则
