# 利润变动深度拆解框架（增收不增利分析）

## 触发场景

当公司财报出现"增收不增利"（营收增长但净利润下滑）时，管理层通常归因于费用增加（销售/研发/管理费用上升）。但这往往只解释了利润下降的一部分原因。**必须优先拆解毛利率变动**，而非直接接受管理层的费用叙事。

## 分析步骤

### Step 1：量化成本增速 vs 收入增速

计算：
- 营业收入 YoY%
- 营业成本 YoY%
- 如果成本增速 >> 收入增速，说明毛利率本身在恶化

示例（特宝生物 2026Q1）：
- 收入 +18.5%，成本 +82.9% → 毛利率从 93.2% 降至 89.5%（-3.7pp）

### Step 2：识别毛利率下滑的驱动因素

对医药/biotech公司，常见原因按影响大小排序：

1. **医保降价/集采降价**（影响最大，最常见）
   - 新药纳入医保后价格通常下降 30-60%
   - 成本刚性（生物制品制造成本不随售价变化）
   - 检查：该产品是否在报告期内首次执行医保价？

2. **产品结构变化**（低毛利品种占比上升）
   - 新产品/仿制药毛利率通常低于成熟独家品种
   - 检查：各产品收入占比变化 + 各产品毛利率区间

3. **产能爬坡期规模不经济**
   - 新产线投产初期：产能利用率低 → 固定成本分摊高
   - 批次良率不稳定 → 损耗率高
   - 检查：在建工程转固情况、产能利用率数据

4. **原材料成本上涨**
   - 检查：主要原材料（培养基、填料、包材）价格变动

5. **税收政策变化**
   - 增值税附加税变化影响"税金及附加"（在毛利之下）
   - 检查：税费明细变动

### Step 3：交叉验证管理层解释的完整性

| 管理层归因 | 实际影响 | 是否充分 |
|-----------|---------|---------|
| 销售费用增加 X 亿 | 影响利润 -X 亿 | 部分 |
| 研发费用增加 Y 亿 | 影响利润 -Y 亿 | 部分 |
| **毛利率下降导致毛利减少 Z 亿** | **影响利润 -Z 亿** | **常被忽略** |

如果 Z > X + Y，说明费用增加不是主因，毛利率结构性变化才是核心矛盾。

## 数据获取方法

- **Wind MCP**：分季度收入/成本/毛利率 → `get_stock_fundamentals`
- **公司一季报/半年报**：通常不披露分产品毛利率，但可推算
- **ESG报告/年报**：可能披露产品医保价格变动细节
- **券商研报**：通常有各产品毛利率拆分估算

## 关键原则

- **不要只看同比，要看环比趋势**：单季度毛利率突变往往有结构性原因
- **新产品纳入医保的第一个完整季度是关键观察窗口**：此时收入结构突变
- **生物制品 vs 化学药**：生物制品的制造成本刚性更强（发酵、纯化周期长），医保降价对毛利率的冲击更剧烈
