# 新控股股东治理分析框架

当上市公司发生控制权变更（国资入主、破产重整、协议转让等）时，需在报告中追加对新控股股东的治理记录分析。以Q&A形式写入附录。

## 分析维度

### 1. 治理风格与历史基调
- **管控模式**：战略管控型 vs 财务管控型 vs 运营管控型
- **对下属企业的授权边界**：是否"补位不越位"？派驻高管的介入深度？
- **合规与风控偏好**：对历史违规问题的处理手法（切割整改 vs 渐进修复）
- **资产配置偏好**：归核聚焦 vs 多元化扩张

### 2. 过往典型整合案例
- 寻找同赛道或类似体量的收购/混改案例
- 关注整合后的关键指标变化：研发投入占比、资产负债率、管理层稳定性、营收/利润趋势
- 区分成功案例与失败案例，客观呈现

### 3. 在当前标的上的"首考"表现
- 入主后是否立即进行管理层洗牌？
- 财务层面是否"止血"（降负债、降融资成本）或"输血"（定增、注资）？
- 历史遗留问题（资金占用、违规担保、信披违规）的整改进度

### 4. 综合评价：优势与隐忧
- **优势**：信用背书、融资成本下降、治理透明度提升、战略定力
- **隐忧**：决策链条变长、激励机制僵化（薪酬总额限制）、文化冲突（央企合规 vs 民企狼性）

## 搜索模式

```
# 搜索特定国资系的整合记录
"<新股东名称>" 收购 企业 公司治理 管理经验
"<新股东名称>" 纾困 民企 破产重整 赋能
"<新股东名称>" 混改 投后 整合 案例
```

## 输出格式

以 Q&A 形式写入报告附录（如 `附录E：关键财务转折点Q&A` 的延续）：

```markdown
### EX. [新股东名称]成为控股股东后，其历史上在企业治理和管理方面的记录如何？

[分四段展开：治理风格→过往案例→首考表现→综合评价]

**总结：** [1-2句定性判断]
```

## 注意事项

- 不写泛泛的"央企赋能"套话，必须有具体案例和数据支撑
- 区分不同国资体系（招商系、华润系、国投系、地方国资等）的治理风格差异
- 对入主不足一年的新股东，明确标注"尚无法全面评估"，仅基于已公开动作判断
- 重点关注医药/科技等高度市场化行业，央企管控与行业特性的冲突风险
