# Wind EDB (economic_data) 查询避坑指南

## 问题描述

`economic_data.get_economic_data` 使用 `metricIdsStr` 自然语言搜索时，返回结果极度嘈杂：
- 大量无关国家数据（泰国、俄罗斯、印尼等）
- 省/区域级细分数据而非全国汇总
- 个别上市公司数据混入
- 已停止更新的 deprecated 指标
- 同一指标多个代码版本（DC标记的重复版本）

**实测案例**：搜索 `"水泥产能利用率"`，返回 100+ 条记录，90% 是泰国/俄罗斯/印尼数据或中国各省环比变化值，真正的全国水泥熟料产能利用率只有一条（code: `T9457464`），淹没在噪音中。

## 应对策略

### 策略 1：加限定词缩小搜索范围

```bash
# ❌ 太宽泛，返回大量无关数据
'{"metricIdsStr":"水泥产能利用率","freq":"年"}'

# ✅ 加"全国"限定
'{"metricIdsStr":"全国水泥产能利用率","freq":"年","searchType":"精确"}'

# ✅ 指定具体品种
'{"metricIdsStr":"中国水泥熟料产能利用率","freq":"年"}'
```

### 策略 2：使用 `analytics_data` 兜底

当 `economic_data` 返回大量噪音且无法通过关键词过滤时，改用：

```bash
node scripts/cli.mjs call analytics_data get_financial_data '{"question":"中国水泥行业过去10年产能利用率"}'
```

`analytics_data` 的后端会先解析查询口径再取数，结果更干净。但注意 `analytics_data` 有使用前提（见 wind-mcp-skill 技能文档第 5 节路由规则）。

### 策略 3：结果解析时的过滤规则

收到 `economic_data` 结果后，按以下规则筛选：
1. **过滤 foreign**：排除包含 `(停止)`、`Thailand`、`Russia`、`Indonesia` 等关键词的记录
2. **过滤 regional**：排除 `华北`、`华东`、`西南` 等区域前缀，保留"中国:"开头的全国数据
3. **过滤 company**：排除包含上市公司名称的记录（如 `塔牌集团`、`海螺水泥`）
4. **优先级**：`source == "国家统计局"` > `source == "根据新闻整理"` > 其他
5. **时间连续性**：优先选择数据覆盖完整的指标（null 值少的）

### 策略 4：`magnitude` 参数陷阱

`magnitude` 参数不接受中文单位简称如 `"亿吨"`，必须使用标准值：
- 正确：`"万"`、`"亿"`、`"百万"`
- 错误：`"亿吨"`、`"万吨"`（会报 `ERROR_PARAM: 无效的量级`）

如果需要以"亿吨"为单位显示数据，取 `"万"` 量级的结果后自行除以 10000。

## 数据断代作为行业信号

当 Wind EDB 中某项官方统计指标在某年后**突然停止更新**（非 deprecated 标记，而是最近若干年全为 null），这本身是一个有价值的信号。

**实测案例**：`"中国利润:水泥行业"`（工信部数据）只到 2021 年，2022-2025 年全为 null。这不是数据缺失，而是**工信部自 2022 年起不再公布水泥行业利润数据**，侧面印证行业已进入大面积亏损、官方不愿披露的阶段。

**解读原则**：
- 如果指标是"根据新闻整理"或第三方来源，null 可能只是没人统计
- 如果指标来源是"国家统计局"、"工信部"等官方机构且突然中断，通常意味着数据"不好看"或统计口径变化
- 遇到断代时，应通过上市公司财报、行业协会等其他渠道交叉验证

## 典型可用查询模式

| 需求 | metricIdsStr | 额外参数 |
|:---|:---|:---|
| 全国产量 | `"中国产量:水泥"` | `freq:"年"` |
| 行业利润 | `"中国利润:水泥行业"` | `freq:"年"` |
| 产能利用率 | `"中国产能利用率:水泥熟料"` | `freq:"年"` |
| 企业数量 | `"规模以上水泥企业数量"` | `freq:"年"` |

> **关键原则**：宁可先用 `analytics_data` 探路确认指标存在和可用，再用 `economic_data` 做精细化控制（频率、量级、时间范围）。不要直接用 `economic_data` 做探索性搜索。
