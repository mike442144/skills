# 上市公司产能变动公告搜索方法

## 适用场景

研究行业产能出清/新增时，从上市公司公告中提取具体产能动作（关停、置换、新建、转型）。

## 工具与命令

```bash
cd /home/mike/skills/ifind-repilot-announcement-search
python3 scripts/fetch_data.py "<公司名> 产能置换 产能 关停 新建 2024-2026" \
  --start-date 2024-01-01T00:00:00 \
  --end-date 2026-06-01T00:00:00
```

## 搜索关键词组合

根据目标不同调整关键词：

| 目标 | 关键词示例 |
|------|-----------|
| 产能退出/关停 | `产能置换 关停 停产 产能退出 生产线出售` |
| 产能新增 | `新建 新增产能 投产 扩建 产能增加` |
| 产能转型 | `转型 新材料 冶金石灰 骨料 环保处置` |
| 超产治理 | `超产 错峰 限产 停产整改` |
| 减值相关 | `资产减值 固定资产减值 生产线减值` |

## 数据分类框架

搜索结果分为三类：

1. **有明确公告证据的产能动作**：记录企业名称、具体动作、数字（产线条数/产能吨数/减值金额）、公告日期和编号
2. **政策引用但无公司具体动作**：年报中引用产能置换政策但未披露本公司具体计划 — 标注"仅引用政策，未见具体公告"
3. **未找到**：搜索无结果或仅找到无关内容 — 明确写"未找到"，不推断不编造

## 产能出清判定标准

**财务亏损 ≠ 产能出清**。判定需要多维交叉：

| 维度 | 信号 | 数据来源 |
|------|------|---------|
| 财务 | 净利润亏损 | 财报/金融数据API |
| 现金流 | 经营现金流为负 | 财报 |
| 物理退出 | 生产线关停/出售公告 | 公告搜索 |
| 资产减值 | 固定资产/在建工程减值 | 公告 |
| 转型 | 旧产线转新材料/其他用途 | 投资者交流纪要 |
| 利用率 | 产能利用率<50% | 行业统计 |

仅满足"财务亏损"一条，不能下"已出清"结论。需同时满足"财务亏损 + 物理退出/资产减值/转型"中至少两项。

## 常见陷阱

- **年报政策段落 ≠ 公司动作**：年报"行业情况"章节经常大段引用国家政策，不等于该公司有相关产能变动。要看"重要事项"、"重大事项"、"资产减值"等章节
- **置换 ≠ 净减**：产能置换是"置出+置入"的组合，需分别统计，净变化可能为正、负或零
- **"低效产能关停"模糊表述**：投资者交流中的口头回答往往没有具体数字，需交叉核对财报减值金额确认规模
- **港股信息披露不足**：H股/A+H公司的港股公告通常不如A股详细，优先查A股公告

## 典型产出格式

按"产能退出类"、"产能新增类"、"未找到"三栏分类，每条记录包含：企业名称、具体动作+数字、公告来源（公告编号+日期）。
