# ifind-repilot F9 银行数据模型 — 查询映射表

> 本文件记录同花顺 iFind F9 模块在银行研究中的查询模式与返回结构。
> 基于 2026-06 杭州银行（600926.SH）和成都银行（601838.SH）研究实战整理。
> F9 模块对银行研究的数据覆盖深度远超 Wind/mx，是银行研究的首选工具。

---

## 核心发现

**ifind F9 是银行研究中最有价值的数据源。** 它返回的 `F9-{bank}-{模块名}` 表格包含 Wind 无法获取的结构化银行专项数据。

## 关键 F9 模块

### 1. `F9-{bank}-银行贷款结构`（最核心模块）

**触发查询模板：** `"{bank}{code}最近3年对公贷款总额、零售贷款总额、贷款总额、存款总额"`

**返回结构：** 报告期 × (数据类型 × 客户类型) 矩阵，数据类型分为：
- `贷款余额` — 各维度贷款金额
- `不良贷款金额` — 各维度不良金额
- `不良贷款率(%)` — 各维度不良率

**维度覆盖：**

| 类别 | 维度 |
|------|------|
| 客户类型 | 个人贷款和垫款 / 票据贴现 / 企业贷款和垫款 |
| 个人贷款细分 | 个人经营性贷款 / 个人消费贷款 / 个人住房贷款 |
| 企业贷款品种 | 其他 / 一般贷款 |
| 企业行业分布 | 电力热力燃气及水 / 房地产业 / 建筑业 / 交通运输仓储邮政 / 科学研究和技术服务 / 批发和零售业 / 水利环境公共设施 / 信息传输软件和信息技术服务 / 制造业 / 租赁和商务服务业 / 其他 |
| 企业地区分布 | 安徽省 / 北京市 / 江苏省 / 上海市 / 深圳地区 / 浙江省 |
| 担保方式 | 保证贷款 / 抵押贷款 / 信用贷款 / 质押贷款 |

**每个行业同时返回贷款余额、不良贷款金额和不良贷款率三个数据行。** 这在 Wind 中几乎无法获取（Wind 对银行行业贷款查询常返回 `None`）。

### 3. `F9-{bank}-银行存款结构`

**触发查询模板：** `"{bank}{code}2023-2025年对公存款、零售存款、活期存款、定期存款"`

**返回结构：** 客户类型 × (个人存款/公司存款) × (活期/定期/保证金/财政性/其他)

### 4. `F9-{bank}-分红`

**触发查询模板：** `"{bank}{code}2023-2025年每股派息DPS、分红总额、分红率、股息率"`

**返回结构：** 历年分红明细，包含现金分红总额、归母净利润、股利支付率、每股股利、股息率。注意：这里的 DPS 是年度累计值，与 Wind 返回的单次分红值可能不同。

### 5. `F9-{bank}-管理层状况`

**触发查询模板：** `"{bank}{code}董事长、行长、高管团队名单"`

**返回结构：** 姓名 / 职务 / 任职日期 / 性别 / 国籍 / 学历 / 出生年份 / 年龄 / 最新薪酬(万元) / 最新持股数(万股) / 个人简历

### 6. `F9-{bank}-员工结构与薪酬变化`

**触发查询模板：** 任何关于员工数量的查询

**返回结构：** 在职人员 / 综合管理人员 / 销售人员 / 技术人员 / 硕士/本科/专科/高中及以下 / 应付员工薪酬 / 人均薪酬 / 人均创收 / 人均创利

### 7. `F9-{bank}-可转债发行`（如适用）

**触发查询模板：** `"{bank}可转债转股价格、转股进度"`

**返回结构：** 发行情况、发行结果（含网上/网下中签率）、申购者名单

## 实战注意事项

1. **单位差异：** ifind F9 银行分析指标的金额单位是"万元"（如 `236,280,562.2` = 23,628 亿元）。贷款结构数据的行业分类单位也是"万元"。

2. **日期格式：** F9 报告期标识为 `2025 年报`、`2024 年报`、`2026-03-31` 等。季度数据（如 `2026-03-31`）的行业分类可能不完整（只有总量，无行业细分）。

3. **`\t` 值表示空：** 部分单元格返回 `\t`（制表符），表示该维度无数据。

4. **query 触发机制：** ifind 根据自然语言 query 的关键词触发不同的 F9 模块。有时需要调整 query 措辞才能触发目标模块。一次 query 可能同时返回多个 F9 模块和数据浏览器结果——这是正常的，按需取用。

5. **peer comparison 的写法：** 多个银行名称可以在一个 query 中合并，如 `"宁波银行、南京银行、成都银行、江苏银行2025年成本收入比"`。返回的 `数据浏览器` 表格会横向排列各银行对比值。一次 query 同时触发所有银行的 F9 银行分析指标模块——这是最高效的同业对比方式，远优于逐家 Wind 查询。

6. **银行贷款结构表的列解析（重要pitfall）：** `F9-{bank}-银行贷款结构` 表极宽（40+列），列顺序为：(1) 客户类型汇总 → (2) 个人贷款细分 → (3) 企业贷款品种 → (4) 行业分布（18+行业）→ (5) 地区分布 → (6) 担保方式。关键注意：个人贷款和垫款同时出现在"客户类型"和"行业"两个分类下（重复列）；空值 `\t` 在不良率行中频繁出现，如果未正确计数会导致后续列错位。最可靠的解析方法：将 贷款余额、不良贷款金额、不良贷款率(%) 三行按相同的列索引并行解析，用 余额×不良率 反算验证不良金额是否匹配。

7. **Wind get_stock_events 对资本运作事件可能失败：** 查询可转债转股、增发等事件时 Wind 可能返回 `UNKNOWN` 错误（"没找到数据"）。此时改用 ifind F9 可转债发行模块（查询模板：`"{bank}{code}可转债转股价格、转股进度、累计转股数量"`）获取发行规模、初始转股价、终止上市日期等完整信息。

## LGFV 敞口估算方法

F9 银行贷款结构模块中，政信类（LGFV）贷款不会被单独标注。它们分布在通常以城投平台和基建项目为主的行业类别中：

- **租赁和商务服务业** — 包含城投公司、国有资本运营平台、基础设施建设投资公司等
- **水利、环境和公共设施管理业** — 包含公共基础设施项目

将这两个行业的贷款余额合计，作为政信类敞口的代理指标。再结合 F9 银行分析指标中的 **最大十家客户贷款比例**（集中度风险指标）判断客户集中度。

实战案例（成都银行 2025年末）：
- 租赁和商务服务业：3,300亿元（不良率 0.10%）
- 水利环境和公共设施管理业：1,005亿元（不良率 0.02%）
- 合计政信类估算敞口：4,305亿元，占贷款总额 50.1%
- 最大十家客户贷款比例：41.67%（同业最高）

政信类贷款的风险评估不能依赖当期不良率（通常极低，0.02-0.10%），而需结合地方财政实力、隐性债务化解政策走向、客户集中度、期限错配等因素综合判断。这类贷款具有"低频高损"特征——平时不形成不良，但一旦发生大规模债务重组，风险可能集中暴露。

## 可转债转股分析与 DPS 追溯调整

当银行发行的可转债发生转股时，股本变化会影响每股指标的横向可比性。完整分析流程：

**第一步：检测股本变化。** 在 F9 分红模块中检查历年"基准股本"。若股本显著增加但无送股/转增事件，通常源于可转债转股。

**第二步：获取可转债信息。** 查询 F9 可转债发行模块，获取：发行规模、初始转股价、终止上市日期（存在=已全部转股/赎回）。

**第三步：计算调整后转股价。**
```
调整后转股价 = 初始转股价 - Σ(历年每股派息)
```
每次现金分红使转股价下调相应 DPS 金额。

**第四步：估算转股情况。**
```
转股数量 = 期末股本 - 期初股本
最大可转股数 = 发行规模 / 调整后转股价
转股比例 = 转股数量 / 最大可转股数
补充核心一级资本 ≈ 转股数量 × 调整后转股价
```

**第五步：DPS 追溯调整。**
```
调整后DPS(YearN) = YearN现金分红总额 / 最新股本
```
确保不同年度的 DPS 在同一股本基数上可比。

实战案例（成都银行 成银转债 110053.SH）：
- 发行：2022年3月，80亿元，初始转股价 14.53元
- 调整后转股价：14.53 - 0.77 - 0.90 - 0.89 = 11.97元（3次分红调整）
- 股本变化：38.14亿 → 42.38亿股（+4.24亿股，+11.1%）
- 转股比例：63.5%（约36.5%被赎回）
- 补充核心一级资本：~50.8亿元
- 终止上市：2025-02-06
- 调整后DPS：2022年0.69元、2023年0.81元、2024年0.89元、2025年0.92元
